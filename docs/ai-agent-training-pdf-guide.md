# คู่มือ AI Agent: ย่อย PDF วิทยากรเข้า Node โครงร่างและกำหนดการอบรม

เอกสารนี้สำหรับ AI Agent ที่ช่วยอ่าน PDF/ไฟล์จากวิทยากร แล้วแปลงข้อมูลมาเติมในแอป **โครงร่างและกำหนดการอบรม**

เป้าหมายคือให้ agent ส่งข้อมูลแบบมีโครงสร้าง ชัดเจน และตรวจสอบได้ ไม่เดาข้อมูลสำคัญเงียบ ๆ

## บทบาทของ AI Agent

AI Agent ต้องช่วยผู้ใช้จากไฟล์ PDF ของวิทยากร เช่น proposal, course outline, syllabus, timetable, profile หรือเอกสารประกอบ แล้วสกัดข้อมูลเพื่อเติม workflow นี้:

1. Step 1: โครงร่างอบรม
2. Step 2: กำหนดการอบรมรายวัน
3. สร้างเอกสารไฟล์เดียว หน้าแรกโครงร่าง หน้าถัดไปกำหนดการวันละ 1 หน้า

Agent ไม่ควรสร้าง field ใหม่เองถ้าแอปมี field เดิมอยู่แล้ว ให้ map เข้าฟอร์มเดิมของโครงร่างอบรมและกำหนดการอบรมเป็นหลัก

## หลักการทำงาน

1. อ่าน PDF ทั้งหมดก่อนสรุป
2. แยกข้อมูลเป็น 3 กลุ่ม:
   - ข้อมูลที่มั่นใจและมีหลักฐานในไฟล์
   - ข้อมูลที่อนุมานได้จากบริบท
   - ข้อมูลที่ขาด ต้องถามผู้ใช้
3. Normalize วันที่ทุกแบบให้กลายเป็น `trainingDays`
4. อย่าเดาวันหยุดหรือวันเว้นวันเอง ให้ยึดข้อความใน PDF หรือคำตอบผู้ใช้
5. ถ้า PDF มีหลาย version หรือข้อมูลขัดกัน ให้บอกจุดขัดแย้งและถามก่อนเติม
6. ถ้าเจอชื่อวิทยากรใหม่ ให้เตรียมข้อมูลเฉพาะชื่อก่อน เพราะประวัติวิทยากรอาจต้องค้นแยกภายหลัง

## วิธีเลือก `trainingDateMode`

### `single_day`

ใช้เมื่อ PDF ระบุวันอบรมวันเดียวชัดเจน

ตัวอย่าง:

- "วันที่ 12 สิงหาคม 2569"
- "Training date: 2026-08-12"

### `continuous_days`

ใช้เมื่อ PDF ระบุช่วงวันที่ต่อเนื่องชัดเจน

ตัวอย่าง:

- "วันที่ 12-14 สิงหาคม 2569"
- "12 to 14 August 2026"

เมื่อใช้ mode นี้ ให้สร้าง `trainingDays` ครบทุกวันในช่วงนั้น ไม่ตัดวันเสาร์อาทิตย์เอง

### `separate_days`

ใช้เมื่อ PDF ระบุวันที่แยกกัน ไม่ใช่ช่วงต่อเนื่อง

ตัวอย่าง:

- "วันที่ 12, 14 และ 18 สิงหาคม 2569"
- "Session 1: Aug 12, Session 2: Aug 19"

ให้ sort วันที่จริงจากเก่าไปใหม่

### `unknown`

ใช้เมื่อ PDF ไม่มีวันที่ หรือวันที่กำกวม เช่น มีหลายวันที่แต่ไม่ชัดว่าเป็นวันอบรมจริงหรือ deadline

## Mapping เข้า Step 1: โครงร่างอบรม

ให้ใช้ฟอร์มโครงร่างอบรมเดิมเป็นหลัก โดย map ข้อมูลประมาณนี้:

- ชื่อหลักสูตร/โครงการ -> ชื่อหลักสูตรในโครงร่าง
- วัตถุประสงค์ -> วัตถุประสงค์
- กลุ่มเป้าหมาย -> กลุ่มเป้าหมายในโครงร่างเท่านั้น ไม่ต้องส่งต่อไปกำหนดการ
- จำนวนผู้เข้าอบรม -> จำนวนผู้เข้าอบรม
- สถานที่ -> สถานที่ในโครงร่าง และใช้กับกำหนดการเฉพาะเมื่อฟอร์มกำหนดการเดิมต้องใช้
- วิธีประเมินผล -> วิธีประเมินผล
- วันอบรม -> ตัวเลือกวันอบรมใน Step 1 และ `trainingDays`

วัตถุประสงค์และวิธีการประเมินผลต้องสอดคล้องกัน ถ้า PDF ระบุวัตถุประสงค์เป็นทักษะปฏิบัติ แต่วิธีประเมินผลเป็นเพียงแบบทดสอบความรู้ หรือมีความไม่สอดคล้องลักษณะเดียวกัน ให้เพิ่ม warning และถามผู้ใช้ก่อนส่งข้อมูลเข้าแอป

ห้ามย้ายหัวข้อหลัก/เนื้อหาไปเป็นข้อมูลกลางของโครงร่าง ถ้าข้อมูลนั้นเป็นหัวข้อเรียนรายช่วงเวลา ให้ใส่ใน Step 2 กำหนดการ

## Mapping เข้า Step 2: กำหนดการอบรม

กำหนดการเป็นรายวัน และแต่ละวันมีตารางเวลาของตัวเอง

ในแต่ละ session ให้พยายามแยก:

- เวลาเริ่ม
- เวลาสิ้นสุด
- หัวข้อ
- เนื้อหาโดยย่อ
- วิทยากร
- หมายเหตุ เช่น พักเบรก, lunch, workshop, Q&A

ถ้า PDF มีหัวข้อแต่ไม่มีเวลา ให้สร้าง session ที่ไม่มีเวลาและเพิ่ม warning ว่า "ไม่พบเวลา"

ถ้า PDF มีเวลาแต่หัวข้อไม่ชัด ให้คงเวลาไว้และเพิ่ม missing field สำหรับหัวข้อ

## กติกาวิทยากร

- ถ้า speaker ตรงกับข้อมูลหลัก ให้ใส่ `foundInMasterData: true`
- ถ้าไม่พบในข้อมูลหลัก ให้ใส่ `foundInMasterData: false`
- อย่าเพิ่มเข้าข้อมูลหลักอัตโนมัติ
- ให้ตั้ง `suggestAddToMaster: true` เมื่อชื่อดูเป็นชื่อบุคคลจริงและถูกใช้ในกำหนดการ
- บันทึกเข้าข้อมูลหลักเฉพาะชื่อเท่านั้นเมื่อผู้ใช้ติ๊ก checkbox ในแอป

## สิ่งที่ต้องถามผู้ใช้

ถามเมื่อข้อมูลเหล่านี้ขาดหรือขัดกัน:

- วันที่อบรมจริง
- หลักสูตร/ชื่อโครงการ
- สถานที่
- ตารางเวลาที่ไม่ครบจนสร้างกำหนดการไม่ได้
- วิทยากรไม่ชัดว่าใครสอนช่วงไหน
- PDF ระบุหลายหลักสูตรในไฟล์เดียว
- มีข้อมูลหลายเวอร์ชัน เช่น วันที่หน้าแรกไม่ตรงกับกำหนดการท้ายไฟล์

## ตัวอย่างคำตอบให้ผู้ใช้

```markdown
## สรุปจาก PDF

พบข้อมูลพอเติม Step 1 และ Step 2 ได้บางส่วน แต่ยังต้องตรวจ 2 จุด:

- วันที่อบรมในหน้าแรกเป็น 12-13 สิงหาคม 2569 แต่ตารางท้ายไฟล์มีเฉพาะ 12 สิงหาคม 2569
- ไม่พบสถานที่อบรม

## ข้อมูลที่จะเติม

- ชื่อหลักสูตร: ...
- รูปแบบวันอบรม: หลายวันติดกัน
- วันอบรม: 2026-08-12 ถึง 2026-08-13
- วิทยากรใหม่ที่พบ: ...

## ต้องถามก่อนสร้างเอกสาร

1. ยืนยันวันที่อบรมใช้ 12-13 สิงหาคม 2569 ใช่ไหม
2. สถานที่อบรมคือที่ไหน
```

## Checklist ก่อนส่งข้อมูลเข้าแอป

- มี `trainingDateMode`
- มี `trainingDays` ที่ normalize แล้ว หรือมี missing field ชัดเจนถ้าทำไม่ได้
- Step 1 มี required field เท่าที่หาได้จาก PDF
- Step 2 แยก session รายวันแล้ว
- วัตถุประสงค์และวิธีการประเมินผลสอดคล้องกัน หรือมี warning ชัดเจนถ้ายังไม่สอดคล้อง
- ไม่ดึงกลุ่มเป้าหมายไปกำหนดการ
- หัวข้อ/เนื้อหาอยู่ในกำหนดการ
- วิทยากรใหม่ไม่ถูกเพิ่ม master data อัตโนมัติ
- ทุกค่าที่ไม่มั่นใจอยู่ใน `warnings` หรือ `missingFields`
